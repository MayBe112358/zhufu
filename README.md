# 祝福集

写给不同的人的祝福页，每个目录是一张独立的单文件网页，互不依赖。

| 目录 | 内容 |
| --- | --- |
| `christmas-2025/` | 2025 年的圣诞树：摄像头手势控制的粒子圣诞树 |
| `xiaochengzi-61/` | 小橙子 · 六一儿童节快乐 |
| `birthday-jiayao/` | 致嘉瑶 · 生日快乐 |
| `birthday-wang-guanlin/` | 致汪冠霖 · 生日快乐 |

## 发布

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
发布后每张页面的地址是 `https://<用户名>.github.io/<仓库名>/<目录>/`。

首页故意不列出各页链接，收到其中一张的人不会顺着看到别人的那张。
